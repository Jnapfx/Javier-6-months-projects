# Archives

This subfolder stores archived versions of projects and important historical snapshots.

## Purpose

- Keep old versions of projects for reference
- Store deprecated code that might be useful later
- Maintain project evolution history
- Backup critical configurations before major changes

## Naming Convention

Use descriptive names with dates:
- `project-name-YYYY-MM-DD/`
- `config-backup-YYYY-MM-DD/`
- `pre-refactor-backup-YYYY-MM-DD/`

## Guidelines

- Always include a README explaining what was archived and why
- Compress large archives to save space
- Document any dependencies or special requirements
- Include the original creation date and reason for archiving
