## 🎯 Focus Area: SOC Analyst

After researching various cybersecurity roles, I chose to pursue the **SOC Analyst** path because it offers a structured way to build technical skills, respond to real threats, and grow in a high-impact, fast-paced environment.

---

## 🛠️ Capstone Project: *Divide & Defend*

**Project Goal:**  
Design a hands-on SOC lab environment using virtual machines and open-source tools to simulate threat detection, alert triage, and incident response. Special focus: using **micro-segmentation** to limit lateral movement between systems.

**Tools & Technologies (Planned):**
- VirtualBox / VMware
- Wazuh (SIEM)
- Filebeat, Winlogbeat, Auditd (log agents)
- Kali Linux (attack simulation: Nmap, Hydra)
- Windows Firewall, UFW, iptables (micro-segmentation)
- OpenVAS (optional vulnerability scanning)
- OTX, AbuseIPDB, MISP (threat intel)

**Key Skills Targeted:**
- SIEM configuration & alerting
- Network administration
- Incident detection and triage
- Firewall rule implementation
- Threat hunting and IOC analysis

## 🧠 Soft Skills Development (Based on Peer Feedback)

### 🔊 Effective Communication
> Goal: Improve professional presence and clarity in group settings.

**Plan (12 weeks):**
- ✅ **30 Days:** Lead 4 huddles or teach-backs. Gather 3+ pieces of feedback.

- 🚀 **90 Days:** Lead a larger session (e.g., skill-share). Be seen as a confident, calm communicator and peer leader.

### ⏱️ Time & Task Management
> Goal: Build a reliable planning system and complete 80%+ of tasks weekly.

**Plan (12 weeks):**
- ✅ **30 Days:** Plan every morning, review every evening. Hit 80% task completion in 3 of 4 weeks.
- 🔄 **60 Days:** Organize tasks by energy/type, conduct weekly reviews. Aim for 80%+ every week.
