# 🧠 Logic 1

## 📁 About This Folder

This folder contains exercises and visuals related to the development of basic algorithmic thinking using Boolean and conditional logic. It is designed to strengthen problem-solving skills through the crafting of logic-driven algorithms and their visual representation.

## 📄 Contents

1. **Crafted Algorithms**  
   - Step-by-step algorithms with at least 6 steps.  
   - Integrates Boolean expressions and conditional logic for decision-making.

2. **Flowchart Visualizations**  
   - Flowcharts designed to mirror the structure of each algorithm.  
   - Uses at least five distinct flowchart symbols including:  
     - `Start`  
     - `Stop`  
     - `Decision`  
     - `Process`  
     - `Input/Output`

3. **Boolean Logic Integration**  
   - Clear Boolean decision points embedded in both algorithm and flowchart.  
   - Examples of logic such as `AND`, `OR`, and `NOT`.

4. **Conditional Logic**  
   - Representation of `IF`, `ELSE`, and nested conditions.  
   - Decision trees aligned with logical steps of the algorithm.

## ✅ Purpose

This project aims to build a strong foundation in logical reasoning, which is essential for programming, software development, and system design.
