# Cybersecurity Basics 1 

## Overview

This project submission addresses the core requirements outlined for the Cybersecurity Basics 1 course. It compiles the essential components expected for a comprehensive cybersecurity project, demonstrating both theoretical understanding and practical application.

## Included Components

### 1. Incident Response Plan
A structured incident response plan is included, outlining methods for detecting security incidents, containment strategies, and steps for eradication and recovery. It also includes an explanation of one major type of cyberattack and how the plan addresses it.

### 2. Comprehensive Security Policy
A formal security policy document is provided, detailing at least three key security rules and guidelines. It includes an embedded incident response plan and explains how the policies uphold the principles of the CIA Triad: Confidentiality, Integrity, and Availability.

### 3. Encryption Techniques
The submission demonstrates encryption and decryption of a sample text using a consistent encryption method (such as AES). It also showcases a hashed text using a standard hashing function (such as MD5 or SHA), illustrating the use of cryptographic techniques.

### 4. Legal and Ethical Compliance
A dedicated section explains how the project ensures compliance with relevant legal and ethical standards. It identifies at least two key regulations and discusses one ethical consideration, clarifying how the approach aligns with cybersecurity best practices and ethical principles.

## Purpose

The purpose of this project is to showcase a foundational understanding of cybersecurity concepts, combining policy design, technical application, and ethical considerations in a cohesive submission.
