## 1. Overview
This project demonstrates the foundational understanding and practical implementation of network security principles within a controlled lab environment.  
Students were required to design, configure, and secure a network following industry standards while documenting methodologies and results.  
The course focused on understanding network structures, implementing access control and firewall configurations, securing wireless communications, and performing incident monitoring and response.

---

## 2. Learning Objectives
- Understand and implement secure network topologies and architectures.  
- Configure and analyze core network security devices, including firewalls, IDS, and IPS.  
- Apply access control measures across different security models.  
- Secure wireless networks through encryption and intrusion prevention mechanisms.  
- Utilize professional network analysis and vulnerability assessment tools.  
- Perform incident detection, analysis, and response with supporting evidence.

---

## 3. Key Implementations

### 3.1 Network Topologies
- Created and analyzed a network topology diagram using one configuration (LAN, WAN, MAN, or PAN).  
- Explained how the chosen topology supports secure communication and network management.  

### 3.2 Network Protocols and Architecture
- Designed a secure network diagram including OSI and TCP/IP layers.  
- Configured subnetting for one subnet and applied specific security protocols to maintain confidentiality and integrity.  

### 3.3 Network Security Fundamentals
- Configured and documented one firewall rule, one IDS, and one IPS system.  
- Demonstrated detection of at least one security event captured by the IDS/IPS.  

### 3.4 Access Control Measures
- Implemented one Access Control List (ACL) for traffic restriction.  
- Applied one access control model (MAC, DAC, or RBAC).  
- Configured at least one user access level to illustrate authorization and privilege management.  

### 3.5 Wireless Network Security
- Configured WPA2/WPA3 encryption for one wireless network.  
- Implemented a Wireless Intrusion Prevention System (WIPS) to block unauthorized access.  

### 3.6 Network Security Tools
- Utilized Wireshark for packet capture and network protocol analysis.  
- Performed one network vulnerability scan using Nmap or OpenVAS.  
- Generated one penetration testing output demonstrating network exposure points.  

### 3.7 Monitoring and Incident Response
- Monitored network activity and identified one security incident.  
- Documented incident response actions, including identification, containment, eradication, and recovery.  
- Supported findings with logs, screenshots, and analytical evidence.
