## DAE project
# 🐕Dog Activity Recommender
### Deadline 05-06-2025

## About project

Dog Activity Recommender is a program that suggests fun activities for your dog based on answers to a few questions about your dog’s energy level, size, and preferences. It helps dog owners find the best games and exercises to keep their pets happy and healthy.

## Project History

This project started with a simple script named **doggy** and gradually evolved through versions like **doggy_v2**, **doggy_v3**, and so on, until reaching **doggy_v_7.0**. With each version, new features and improvements were added.

## doggy_v_7.0 – Core Functionality Complete
This release includes the complete backend logic along with a fully developed graphical interface using Tkinter. The GUI enhances usability and provides an intuitive experience for users. Further improvements and additional features will be introduced in future updates.


## ✅ Features

- 💡 **Smart Backend Logic**  
  Evaluates your dog’s profile to suggest personalized activities.

- 🐾 **Tailored Questions**  
  Based on your dog’s energy level, size, temperament, and preferences.

- 🎯 **Personalized Recommendations**  
  Designed to promote your pet’s health, happiness, and well-being.

- 🖥️ **User-Friendly Interface (Tkinter)**  
  Intuitive GUI built with Tkinter for a smooth user experience.

- 🌄 **Image Support**  
  Integrated with the Pillow library to display and handle images.

- ⛅ **Weather Integration**  
  Recommends activities suitable for current weather conditions.

- 🌗 **Light & Dark Theme Toggle**  
  Switch themes for comfort and aesthetics.

- 🖱️ **Hover Effects**  
  Enhanced button interactivity for better usability.

- 📋 **Copy to Clipboard**  
  Instantly copy your dog’s recommended activities.

- 📄 **Export to .TXT File**  
  Save activity results to a text file for easy reference.


  ## 🚀 Future Plans

- 🤖 **AI-Powered Recommendations**  
  In future releases, we plan to integrate AI features that will make the activity suggestions smarter and virtually infinite — dynamically adapting to your dog's evolving needs, preferences, and behavior patterns.


## Technologies Used

- Python 3.13.3  
- Tkinter (for upcoming GUI)  
- Pillow (for image handling)

## Installation

1. Clone this repository or download the files.  
2. Make sure Python 3.13.3 is installed on your system.  
3. Install the required Python libraries by running:

   pip install pillow

4. Tkinter usually comes pre-installed with Python. If not, install it using:

   sudo apt-get install python3-tk  # for Linux

## Usage

To run the program, open a terminal and execute:

   python doggy_v_7.0.py

Follow the prompts to answer questions about your dog and receive personalized recommendations.
